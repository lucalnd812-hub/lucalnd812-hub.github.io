# Griff-Website

Statische Seite ohne Build-Schritt und ohne externe Anfragen: `index.html`, `datenschutz.html`,
`impressum.html`, `style.css`, `assets/`, `fonts/` (Bricolage Grotesque und Inter, beide OFL).

Veröffentlicht über GitHub Pages im Repository `lucalnd812-hub/lucalnd812-hub.github.io`.

Hosten lässt sie sich überall, wo statische Dateien liegen dürfen (z. B. GitHub Pages, Cloudflare
Pages, Netlify) – einfach den Ordner `site/` hochladen.
